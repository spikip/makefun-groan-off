## About this entry

The line is a dad joke built on a question every dad gets asked at
some point: why does the moon only come out at night? The answer is
delivered dead straight, as if it were a fact of astronomy, and the
twist is that the moon is simply working the night shift so the sun
can have the day off. That image does the whole joke, the sun
clocking off while the moon clocks in, and it is the kind of
explanation a dad would give with a straight face at the dinner
table. The setup and the punchline live inside the one line, nothing
is wasted, and it stays well inside the one hundred and forty
character cap. The program holds the line, checks it against that
cap, and writes it to /output/entry.txt exactly as the bounty asks.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
